# ForesightEstate

Проект анализа объявлений о недвижимости и прогнозирования цены.

## Порядок работы

1. Установить зависимости: `python -m pip install -r requirements.txt`.
2. Запустить `notebooks/01_eda_v1.4.ipynb` — исследование данных.
3. Запустить `notebooks/02_preprocessing_v1.5.ipynb` — предварительная обработка, разбиение и проверка отсутствия утечек.
4. Запустить notebooks/03_modeling_v1.0.ipynb — сравнение 13 моделей и сохранение финалиста.
5. Проверить модуль: `python -m unittest discover -s tests -v`.

Ноутбук этапа 2 содержит весь код обработки и не импортирует src/. Для первого получения исторических курсов TCMB нужен интернет; затем он использует локальную копию data/external/tcmb_rates_2018-2019.csv.

Исходные данные читаются из папки `data/`. Второй ноутбук сохраняет `data/processed/split_ids.csv` и обученные на тренировочной выборке преобразователи в `models/`.

При кросс-валидации преобразователи необходимо обучать внутри каждого тренировочного фолда, а не использовать заранее сохранённый экземпляр. Интерпретация `listing_type == 1` как продажи основана на исследовании данных; при наличии официального описания кодов её следует сверить.

Версия 03_modeling_v1.0.ipynb пока использует предобработку v1.4; изменения v1.5 ещё не применены к сохранённой модели.

notebooks/03_modeling_v1.1.ipynb сравнивает обработку v1.4 и v1.5 на общей validation; убедительного улучшения не найдено, поэтому модель приложения не заменена.

notebooks/03_modeling_v1.2.ipynb проверяет три стратегии площади для квартир только на validation; полное удаление строк без площади не улучшило качество на всех квартирах.
