## О проекте

ForesightEstate объединяет исследование объявлений о недвижимости, модели машинного обучения и интерактивное приложение. Укажите характеристики жилья, чтобы получить ориентировочную оценку стоимости в турецких лирах и изучить данные на карте и графиках.

> Модель обучена на исторических объявлениях. Результат помогает исследовать рынок и не является актуальной котировкой или профессиональной оценкой объекта. Диапазон ошибки отражает исторический MAE, а не доверительный интервал.

## Возможности

- Оценка стоимости жилья по его характеристикам с помощью обученных моделей.
- Отдельная модель для объектов среднего ценового сегмента.
- Интерактивная аналитика и карта рынка в Dash.
- Исследование данных, подготовка признаков и сравнение моделей в Jupyter Notebook.
- Генерация иллюстрации объекта через OpenRouter (по желанию).

Карта показывает агрегаты по провинциям и их административным центрам: в исходных данных нет координат отдельных объявлений, поэтому маркеры не являются адресами объектов.

## Запуск

Нужен Python 3.12. В корне проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run_app.py
```

После запуска:

- Streamlit: <http://127.0.0.1:8501>
- Dash: <http://127.0.0.1:8050>

Для завершения нажмите `Ctrl+C`. Дополнительные пакеты для анализа и ноутбуков устанавливаются отдельно:

```powershell
python -m pip install -r requirements-analysis.txt
```

## Генерация изображения объекта

Чтобы включить генерацию изображения, задайте `OPENROUTER_API_KEY` в переменных окружения или в локальном `.streamlit/secrets.toml`. Не добавляйте секретный ключ в Git. Без ключа основная оценка и аналитика доступны без этой функции. Бесплатная модель генерации может временно ограничивать запросы.

## Структура проекта

```text
.
├── app.py                    # приложение Streamlit
├── dashboard.py              # аналитический Dash-дашборд
├── run_app.py                # запуск приложения и дашборда
├── src/                      # модели, обработка данных и интеграции
├── notebooks/                # EDA, подготовка данных и эксперименты
├── data/                     # исходные и подготовленные данные
├── models/                   # сохранённые модели и преобразователи
├── assets/                   # изображения и стили интерфейса
├── tests/                    # модульные тесты
├── requirements.txt          # зависимости приложения
└── requirements-analysis.txt # зависимости для анализа данных
```

## Развёртывание в Streamlit Community Cloud

1. Создайте приложение из репозитория `Saekikes42/ForesightEstate`, ветки `main`, указав `app.py` как основной файл.
2. В настройках приложения выберите Python 3.12.
3. Если нужна генерация изображений, добавьте `OPENROUTER_API_KEY` в раздел **Secrets**.
4. Нажмите **Deploy**. Для облачного приложения достаточно зависимостей из `requirements.txt`; ноутбукам нужен `requirements-analysis.txt`.

В репозитории должны быть доступны файлы моделей, необходимые приложению, а также данные, которые оно загружает при старте.

## Данные и источники

Данные объявлений содержат исторические цены и могут не отражать текущую ситуацию на рынке. Координаты административных центров провинций получены из [turkiye-provinces-dataset](https://github.com/brkunver/turkiye-provinces-dataset), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
