# ForesightEstate

Проект анализа объявлений о недвижимости и прогнозирования цены.

## Порядок работы

1. Установить зависимости: `python -m pip install -r requirements.txt`.
2. Запустить `notebooks/01_eda_v1.4.ipynb` — исследование данных.
3. Запустить `notebooks/02_preprocessing_v1.5.ipynb` — предварительная обработка, разбиение и проверка отсутствия утечек.
4. Запустить notebooks/03_modeling_v1.0.ipynb — сравнение 13 моделей и сохранение финалиста.
5. Проверить модуль: `python -m unittest discover -s tests -v`.

Ноутбук этапа 2 содержит весь код обработки и не импортирует src/. Для первого получения исторических курсов TCMB нужен интернет; затем он использует локальную копию data/external/tcmb_rates_2018-2019.csv.

Исходные данные читаются из папки `data/`. Второй ноутбук сохраняет `data/processed/split_ids.csv` и обученные на тренировочной выборке преобразователи в `models/`.

При кросс-валидации преобразователи необходимо обучать внутри каждого тренировочного фолда, а не использовать заранее сохранённый экземпляр. Интерпретация `listing_type == 1` как продажи основана на исследовании данных; при наличии официального описания кодов её следует сверить.

Версия 03_modeling_v1.0.ipynb пока использует предобработку v1.4; изменения v1.5 ещё не применены к сохранённой модели.

notebooks/03_modeling_v1.1.ipynb сравнивает обработку v1.4 и v1.5 на общей validation; убедительного улучшения не найдено, поэтому модель приложения не заменена.

notebooks/03_modeling_v1.2.ipynb проверяет три стратегии площади для квартир только на validation; полное удаление строк без площади не улучшило качество на всех квартирах.

## Приложение: этап 4

Запуск из корня проекта:

```powershell
python -m pip install -r requirements.txt
python run_app.py
```

Откройте http://127.0.0.1:8501. Dash-дашборд запускается автоматически по адресу http://127.0.0.1:8050. Для остановки нажмите Ctrl+C.

Форма использует две уже обученные модели: общую и модель среднего сегмента. Последняя обучена на объявлениях с ценой 138–750 тыс. TRY. Модель загружается один раз в памяти сервера. Диапазон ±MAE — ориентир исторической ошибки, а не статистический доверительный интервал. Цены исходного датасета исторические и не являются текущими рыночными котировками.

После расчёта цены можно нажать «Сгенерировать фото объекта». OpenRouter получает параметры этого объявления и рассчитанную цену и создаёт фотореалистичное изображение через бесплатную модель `inclusionai/ming-image-0.1-design`. Для работы задайте `OPENROUTER_API_KEY` в переменных окружения или `.streamlit/secrets.toml`; не публикуйте ключ в Git. Бесплатная модель может ограничивать частоту запросов и временно быть недоступна.

Исходный датасет не содержит координат объявлений. Карта Dash агрегирует их по провинции и ставит маркер в административном центре. Координаты получены из [turkiye-provinces-dataset](https://github.com/brkunver/turkiye-provinces-dataset), лицензия CC BY 4.0. Маркеры не обозначают точные адреса объектов.



## Развёртывание на Streamlit Community Cloud

1. Запушьте проект в GitHub. В Streamlit Community Cloud выберите **Create app**, репозиторий Saekikes42/ForesightEstate, ветку main, файл приложения app.py.
2. В **Advanced settings** выберите Python 3.12. В поле **Secrets** вставьте содержимое локального файла .streamlit/secrets.toml с ключом OPENROUTER_API_KEY. Этот локальный файл добавлен в .gitignore; не добавляйте его в Git.
3. Нажмите **Deploy**. Аналитика встроена во вкладку Streamlit, поэтому в облаке работает по адресу приложения. Отдельный Dash запускается локально через python run_app.py.
4. Для запуска ноутбуков установите дополнительные пакеты: python -m pip install -r requirements-analysis.txt. Для облачного приложения достаточно requirements.txt.

Файлы моделей models/app_general.joblib и models/app_middle.joblib, исходный CSV и таблица координат должны находиться в репозитории: облачное приложение загружает их при запуске.
